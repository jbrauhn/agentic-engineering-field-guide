Execution

Execution is where agents earn their leverage: they can work quickly, use tools, observe results, diagnose failures, retry, and choose local implementation steps.

What it is

Bounded adaptive work against an approved Contract and reviewed Plan.

Why it matters

Real implementation is not perfectly predictable; the agent needs room to respond to evidence.

Failure prevented

Autonomous wandering, endless retries, and quiet scope change.

Core philosophy

Delegate local adaptation; preserve Contract and Plan boundaries.

Local adaptation means: the agent may choose implementation steps, diagnose failures, and adjust technical approach inside the bounded Plan. If the Plan is wrong, route back to Planning. If the Contract should change, submit a Contract change proposal.

More agents ≠ more agentic. Single-agent, fresh-agent relay, parallel workers, Maker → Checker, and coordinated multi-agent are patterns selected by task shape.
