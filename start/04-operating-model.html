How the system works

0 · Loop Context

Identify the kind of work

Lifecycle context and Plan category shape the controls and proof that follow.

1 · Contract

Define the outcome before building

Goal states the outcome, Spec defines meaning and boundaries, Proof states required evidence.

2 · Planning

Design the route and tasks

Orient to architecture/code, make decisions, select Planning Depth/Method, create increments and executable tasks, map dependencies, and plan verification.

3 · Execution

Build inside the boundaries

Agents use tools, observe, retry, and adapt local implementation without silently changing Contract or Plan.

4 · Validation

Prove the outcome

Independent checks compare delivered evidence against Contract Proof.

5 · Human Owner

Own consequential judgment

Humans bring context, logic, ingenuity, creativity, judgment, authority, and accountability.
