Progressive elaboration

Keep the main layer concise, then expose optional detail on demand: Planning Method iThe required Planning field that describes how work will be sliced and ordered. The circled-i reveals this second layer only when the learner needs it.

Use tooltips selectively. They are for terminology, choices, and controls whose second layer adds value without belonging in the primary reading flow.

Navigation

Section navigation is sticky. The current learning section uses a subtle translucent orange state. Journey pages keep Previous / Next in the top bar. Left/right arrows navigate, H returns Home, Escape closes dropdowns, and clicking elsewhere closes an open dropdown.
