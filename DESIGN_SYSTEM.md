# Agentic Engineering Field Guide — Design System

## Intent
A technical whiteboard and engineering reference: serious, calm, progressively disclosed, and coherent across independently authored pages.

## Palette
- Background `#07111d`
- Surface `#0f1c2c`
- Text `#eef5ff`
- Muted `#b8c5d8`
- Blue `#64bfff` — information
- Teal `#58d4c2` — execution / active work
- Green `#59d68d` — validation / success
- Gold `#ffd166` — Contract / decisions / human cues
- Orange `#ffad5f` — attention / selected section / experiments
- Purple `#b89aff` — planning / architecture / detailed reference
- Red `#ff8585` — blocked / failure / high risk

## Navigation
- Sticky site shell
- Stable Previous / Next controls on journey pages
- Left/right arrows or PageUp/PageDown navigate the current journey
- `H` returns Home
- `Esc` closes dropdowns
- Clicking outside a dropdown closes it

## Progressive elaboration
Circled `i` tooltips reveal a second layer of detail without bloating the primary explanation. Use them for terminology, planning choices, memory patterns, governance, and standards where optional depth adds value.

## Learning hierarchy
- Start Here — the map
- Explore the System — why / philosophy / interactions
- Go Deeper — mechanics / implementation
- Learn by Doing — guided practice

## Standing design principle
**Heavier process is not more mature.** Make rigor visible without making every task feel heavyweight.
