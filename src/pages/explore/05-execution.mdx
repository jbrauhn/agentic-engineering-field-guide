Execution is where agents earn their leverage: they can work quickly, use tools, observe results, diagnose failures, retry, and choose local implementation steps.

<div className="grid four">
  <div className="card"><h3>What it is</h3><p className="muted">Bounded adaptive work against an approved Contract and reviewed Plan.</p></div>
  <div className="card"><h3>Why it matters</h3><p className="muted">Real implementation is not perfectly predictable; the agent needs room to respond to evidence.</p></div>
  <div className="card"><h3>Failure prevented</h3><p className="muted">Autonomous wandering, endless retries, and quiet scope change.</p></div>
  <div className="card teal-line"><h3>Core philosophy</h3><p className="muted">Delegate local adaptation; preserve Contract and Plan boundaries.</p></div>
</div>

<div className="callout good"><strong>Local adaptation means:</strong> the agent may choose implementation steps, diagnose failures, and adjust technical approach inside the bounded Plan. If the Plan is wrong, route back to Planning. If the Contract should change, submit a Contract change proposal.</div>

**More agents ≠ more agentic.** Single-agent, fresh-agent relay, parallel workers, Maker → Checker, and coordinated multi-agent are patterns selected by task shape.
