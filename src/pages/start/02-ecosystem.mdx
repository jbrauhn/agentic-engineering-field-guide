<div className="callout"><strong>Model ≠ Agent. Tool ≠ Agent. Workflow ≠ necessarily Agent. Multi-agent ≠ automatically better.</strong></div>

A useful teaching simplification is: **Model + Instructions + Context + Tools + Runtime/Loop + State + Controls = an agentic worker.** One or more workers plus orchestration, integrations, verification, and governance become an agentic system.

**Model Context Protocol (MCP)** equips a worker with tools and context. **Agent2Agent (A2A)** supports communication between independent agents. Neither protocol is itself an agent.
