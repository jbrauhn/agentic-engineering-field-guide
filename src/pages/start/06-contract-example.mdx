<div className="grid three">
  <div className="card gold-line"><span className="pill gold">Goal</span><h3>Desired outcome</h3><p className="muted">Deliver a secure internal task-tracking application that replaces spreadsheet-based coordination.</p></div>
  <div className="card gold-line"><span className="pill gold">Spec</span><h3>What must be true</h3><p className="muted">Create, assign, reassign, and complete tasks; email reminders; Azure deployment; Entra ID. Explicit non-goals keep adjacent scope out.</p></div>

<div className="callout good"><strong>Human:</strong> articulate, correct, choose. <strong>AI:</strong> interview, structure, challenge, expose assumptions, draft.</div>

**Proof is not the test plan.** Proof states the evidence that must exist. Planning later decides how tests, evals, reviews, environments, fixtures, and instrumentation will produce that evidence.
